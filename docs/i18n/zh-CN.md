# PeMeO · 中文（简体）

**以人为本，向善而行！**

## 让技术向前，让人始终在中心。

一句话、一段经历、一次慎重的确认，背后都是一个人的生活。我们希望技术帮助你理解生活、保有选择，并与重要的人和事保持联系。

我们创造的每一个产品、项目和技术，都应从人的真实需要出发，尊重尊严与自主，努力为个人、家庭和社会带来益处。

1. 尊重自主：说明重要操作及其后果，把选择留在人手中。
2. 尊重表达：区分原话、观察、推断与确认，说明来源和不确定性。
3. 尊重边界：减少数据收集与暴露，说明保存、共享和删除的实际限制。
4. 检验帮助：关注谁受益、谁可能受伤害；发现错误后解释、纠正并承担责任。
5. 诚实面对能力：区分愿景、已实现功能和已验证结果，欢迎审查与改进。

PeMeO Core 从清楚记录表达、来源和确认开始。原始记录采用追加式存储；通行密钥把确认动作绑定到具体内容。凭据验证不证明内容本身真实，管理员和服务进程仍在信任边界内。

实验性开发者预览工作稿，供合成资料评估。完整个人记忆、家庭助理与真实 AI 推断入口仍是未来工作。

这些理念指导设计与协作，不增加 Apache-2.0 使用限制，不替代安全机制，也不表示系统可以自动判断善恶。
